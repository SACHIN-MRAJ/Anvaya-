## 🚀 How to Deploy to Netlify in 30 Seconds

### Method 1: Netlify Drop (Instant Drag & Drop, No Setup Required)
1. Open **[https://app.netlify.com/drop](https://app.netlify.com/drop)** in your web browser.
2. Sign in or continue with GitHub.
3. Drag and drop this entire `showcase` folder into the dropzone.
4. Netlify will instantly deploy it and give you a live public URL (e.g., `https://anumati-anvaya.netlify.app`) in under 5 seconds!

### Method 2: Connect via GitHub
If you link your GitHub repository (`https://github.com/SACHIN-MRAJ/Anvaya-`) to Netlify:
* **Base directory:** Leave empty (root)
* **Build command:** Leave empty
* **Publish directory:** `showcase`
* Click **Deploy Site** — Netlify will deploy it automatically and redeploy whenever you push!
